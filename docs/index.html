FULL-STACK PORTFOLIO DEMO

Planroom.

A financial planning workspace with a client questionnaire, persistent sessions and a savings projection. React, FastAPI and PostgreSQL.

پلن‌روم یک نمونه‌کار فول‌استک با داده‌های ساختگی است. این صفحه فقط بخش تخمین زمان را نمایش می‌دهد و اطلاعاتی را ذخیره نمی‌کند.

Try a sample projection

Illustrative, assumes zero growth and monthly contributions. Nothing is sent or stored.

Run the full workspace

Clone the repository, copy .env.example to .env, and run:

docker compose up --build --wait

Then open the local app on port 8088 and choose Explore with sample data. The full app includes account and questionnaire flows; this page does not.

Planroom is a software portfolio demo, not financial advice.
